# 7X Engine 1.1.3

Adds a native **Credits** page, accessible at **Settings → Credits** / **設定 → 製作人員**. Developer credit: **Zeca**.

The page follows the existing charcoal/cyan palette and measured-window typography, supports Traditional Chinese and English, and scrolls when needed. Back returns to Settings, then Home. It uses the existing panel inside the Activity or floating overlay; opening credits does not start or stop playback.

Version code 113, same package and signing certificate for overwrite installation. Audio synthesis, the 4000-RPM BOV rule, gearbox, seven presets, ECARX inputs, routes and permissions are unchanged.
